# Славян решил переждать всё в деревне… 🏚️🚐

Шуточная браузерная 3D survival-игра-пародия для друзей. Главный герой —
**Славян** — прячется в мрачной славянской деревне от смешных «бусиков»,
которые патрулируют разбитые дороги и пытаются его найти. Задача — скрываться
как можно дольше и набрать рекорд.

> Это юмористическая пародия. Без политики, без реалистичного насилия — просто
> Славян, туман, грязь и настырные микроавтобусы.

## Геймплей

- **Движение:** `W A S D` (или стрелки), бег — `Shift`. На телефоне — джойстик
  слева и кнопка бега справа.
- **Прячься:** за домами, в **сарае** (лучшее укрытие), в **лесу**, на огородах.
- **Погоня:** если бусик замечает Славяна — начинается погоня. Оторвись и
  спрячься на несколько секунд, чтобы её прекратить (это засчитывается как побег).
- **Припасы:** ☕ кофе и 🥤 энергетик дают ускорение, 🍜 дошик лечит,
  🥒 огурец — просто огурец.
- **NPC:** деревенские жители бродят по деревне. Иногда «сдают» Славяна
  ближайшему патрулю, а иногда отвлекают бусик: «Да не видел я никакого Славика!».
- **Сложность растёт:** каждые 2 минуты добавляется новый бусик, растут скорость
  и радиус обнаружения. Через 15 минут — режим настоящего хаоса.
- **Очки:** за время выживания, побеги и найденные припасы. Игра не
  заканчивается победой — это survival, есть только рекорд.

## Стек

React · TypeScript · Vite · Three.js · React Three Fiber · @react-three/drei ·
Zustand · Framer Motion · Tailwind CSS.

Все 3D-модели (Славян, бусики, дома, церковь, деревья, кладбище, трактор и т.д.)
сгенерированы процедурно кодом на Three.js — внешних ассетов нет.


Сборка и предпросмотр продакшена:

```bash

npm run preview
```

```bash

```

## Деплой на GitHub Pages

В репозитории уже есть workflow `.github/workflows/deploy.yml`.

1. Запушь проект в репозиторий на GitHub (ветка `main` или `master`).
2. В настройках репозитория: **Settings → Pages → Build and deployment →
   Source → GitHub Actions**.
3. При каждом пуше в основную ветку игра автоматически соберётся и
   опубликуется. Ссылка появится во вкладке **Actions / Pages**.

`vite.config.ts` использует `base: './'` (относительные пути), поэтому игра
работает и локально, и в подкаталоге `https://<user>.github.io/<repo>/`
без дополнительной настройки.

## Структура проекта

```
src/
  components/
    game/        # Canvas, сцена, свет, дождь
    models/      # процедурные модели (Славян, бусик, NPC)
    world/       # земля, дороги, дома, лес, кладбище, заборы, реквизит
  entities/      # игрок, патрули, NPC, припасы (поведение)
  systems/       # GameLoop — «мозг» игры (AI, погоня, сложность, очки)
  ui/            # HUD, меню, экран поражения, сообщения, миникарта, тач-контролы
  game/          # константы, генерация мира, runtime-стейт, ввод, RNG
  store/         # Zustand-стор
```
